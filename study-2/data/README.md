# Study 2 Data

This directory is reserved for selected data and derived results supporting Study 2.

Materials may include:

- persistent identifiers and permitted bibliographic metadata;
- final stance, theme, study-design, and evidence-domain labels;
- ensemble-agreement and adjudication records;
- derived tables and analysis results; and
- sanitized model outputs that do not reproduce restricted abstract or full-text content.

Copyrighted abstracts and article full texts must not be uploaded. Each released file should be described in this README when it is added, including its contents, format, and relationship to the published analysis.
